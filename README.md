# 🔎 Search Filter Project

This is a simple real-time search filter created using HTML, CSS, and JavaScript. It allows users to search and filter a list of technologies dynamically as they type.

---

## 🔗 Live Demo

👉 [Click here to view the live project](https://msdhinesh45.github.io/search-functionality/)

---

## 🎯 Features

- Real-time search as you type
- Shows matching items only
- Hides non-matching items automatically
- Simple and clean UI design

## 🔍 How It Works

- When the page loads, all items are hidden initially.
- As the user types in the input box, JavaScript checks if the list items (`li`) include the typed text.
- If a match is found, the corresponding item is displayed; otherwise, it remains hidden.
